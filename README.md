# Calculadora La Solución (Estilo Mockup)

Aplicación web diseñada con Streamlit para resolver funciones, derivadas, integrales y límites con una interfaz visual amigable inspirada en tarjetas modernas.

## Características

- Interfaz tipo tarjeta con fondo azul claro
- Resultado resaltado en amarillo
- Explicación paso a paso
- 100% en español

## Uso en Streamlit Cloud

1. Sube estos archivos a GitHub
2. Ve a: https://share.streamlit.io/deploy
3. Archivo principal: `calculadora_la_solucion_mockup_estilo.py`
4. Rama: `main`
