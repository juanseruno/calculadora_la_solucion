# Calculadora La Solución (Versión Total Integrada)

App educativa con IA y visual moderno para resolver funciones, derivadas, integrales y límites.

## Características:
- Fondo con imagen matemática personalizada
- Gráfica interactiva de funciones
- Resultado destacado
- Pasos explicativos numerados
- Exportación de resultado
- Historial de operaciones

## Cómo desplegar en Streamlit
1. Sube los archivos a GitHub (con .streamlit/config.toml si deseas tema claro)
2. Ve a https://share.streamlit.io/deploy
3. Archivo principal: `calculadora_la_solucion_total_integrada.py`
