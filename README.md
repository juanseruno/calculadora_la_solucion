# Calculadora La Solución (Web)

Versión compatible con Streamlit Cloud: resolución de funciones, derivadas, integrales, límites, evaluación paso a paso.

## Cómo desplegar

1. Sube estos archivos a un repositorio GitHub.
2. Ve a https://share.streamlit.io/deploy
3. Usa:
   - Archivo principal: `calculadora_la_solucion_web.py`
   - Rama: `main`
